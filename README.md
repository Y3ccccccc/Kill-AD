# 杀死广告（Kill-AD）

自动跳过 Android 应用开屏广告的小工具，基于系统无障碍服务。**不联网、不收集数据、无广告、不需要 Root。**

## 它是怎么工作的

1. **检测应用切换**：无障碍服务收到前台窗口变化（包名变了）时开始工作
2. **前 20 秒，每秒扫 10 次**：读取当前屏幕的控件树（所有窗口都扫一遍）
3. **见到关键词就点**：`跳过` / `跳过3s` / `关闭广告` / `关闭`，能直接触发控件点击就点控件，不能就按控件中心坐标模拟点击
4. **三发连点**：最多连点 3 次
5. **补充阶段**：三发用完不结束，改为**每秒 5 次、再扫 5 秒**；这期间每次检测到只点 1 下，最多再 3 下
6. **自动停止**：点击次数用完、或时间到，立刻停止扫描和点击，直到你下次打开应用

## 什么时候会停下来

- 切到**桌面 / 最近任务 / 状态栏 / 系统文件选择器**：当前这轮扫描立即终止
- 总开关关闭：服务完全不工作
- 时间到或点击次数用完

这些都是为了避免在正常界面上乱点。

## 图片广告兜底（默认关闭）

部分应用的开屏广告是**整张图片**，无障碍读不到任何按钮（例如菜鸟）。开启「角落兜底」后，一旦发现完全读不到内容，会在右上角三个位置各盲点一次，点完立即停止。

> 不建议开启：没有开屏广告的应用进入后，也会触发盲点。

## 为什么有些广告跳不掉

无障碍服务只能读控件树里的文字，**拿不到屏幕像素**：

| 广告实现方式 | 能否跳过 |
|---|---|
| 原生文字按钮「跳过」 | 能，秒点 |
| WebView 里的 H5 跳过 | 多数能 |
| 整图 / 视频 + 自绘按钮 | 读不到，只能靠坐标兜底 |
| 控件被标记为无障碍忽略 | 完全读不到 |

百度系产品（尤其百度网盘）会在倒计时期间向无障碍暴露**首页内容**而不是广告界面，「跳过」按钮出现得比画面晚几秒，属于已知无解的情况。

## 构建

不需要 Gradle，只要 JDK 17 + Android SDK（build-tools 的 `aapt`/`d8`、platform 的 `android.jar`）：

```bash
./build.sh
```

产物在 `build/SplashSkip.apk`。
