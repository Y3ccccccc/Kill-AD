# 杀死广告（内部名：跳过开屏广告）

一个开屏广告自动跳过工具，用 Android 无障碍服务实现。不联网、不收集数据、无广告。

## 功能

- 打开应用后 20 秒内，每秒扫 10 次屏幕，检测到「跳过 / 关闭广告 / 关闭」就点
- 前三次点击用完后，继续以每秒 5 次的频率再扫 5 秒，每次检测到只点一下（最多 3 下）
- 图片型广告（无障碍读不到按钮）可选「角落兜底」：右上角三个位置各盲点一次，点完即停
- 切到桌面、最近任务、状态栏、系统文件选择器时立即终止，不误触
- 总开关：关闭后服务完全不工作

## 原理与限制

无障碍服务只能读到控件树里的文字，拿不到像素：

| 广告实现 | 结果 |
|---|---|
| 原生文字按钮「跳过」 | 能跳，秒点 |
| WebView 里的 H5 跳过 | 多数能 |
| 整图 / 视频 + 自绘按钮 | 读不到，只能靠坐标兜底 |
| 控件被标记无障碍忽略 | 完全读不到 |

百度系广告（尤其百度网盘）会在倒计时期间不给无障碍暴露「跳过」，属于已知无解的情况。

## 构建

不依赖 Gradle，只需要 JDK 17 + Android SDK（build-tools 的 aapt/d8、platform 的 android.jar）：
```bash
./build.sh
```
产物在 `build/SplashSkip.apk`。
