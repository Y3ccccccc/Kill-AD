# 杀死广告（Kill-AD）

自动跳过 Android 应用开屏广告的小工具，基于系统无障碍服务。**不联网、不收集数据、无广告、不需要 Root。**

## 它是怎么工作的

1. **检测应用切换**：无障碍服务收到前台窗口变化（包名变了）时开始工作
2. **第一阶段：20 秒**，每秒扫 10 次当前屏幕的控件树（所有窗口都会扫）
3. **见到关键词就点**：`跳过` / `跳过3s` / `关闭广告` / `关闭`，能点控件就点控件，不能就按坐标模拟点击
4. **最多三发**：点满 3 次，或点完 1 秒内扫不到关键字（说明广告已关掉），立刻进入第二阶段
5. **第二阶段：5 秒巡视期**：只观察，不再点击
   - 你在该应用里点 / 长按 / 滑动 / 输入 → 立即终止，内部开关归零
   - 5 秒没动静 → 也终止
6. 第一阶段里，**前 3 秒不判手势**（那是你点应用图标的手势），3 秒之后你在该应用里任何操作都会立即终止

终止后什么都不做，直到你下一次切换应用。

## 两个开关

| 开关 | 谁能改 | 作用 |
|---|---|---|
| 总开关 | 你 | 关掉之后服务完全不工作 |
| 内部总开关 | 只有服务自己（界面置灰不可点） | 每次换应用自动打开，终止时自动关闭，防止多余操作 |

## 图片广告兜底（默认关闭，永远默认关）

部分应用的开屏广告是**整张图片**，无障碍读不到任何按钮（例如菜鸟）。开启后，一旦发现完全读不到内容，会在右上角三个位置各盲点一次，点完立即停止。

> 不建议开启：没有开屏广告的应用进入后，也会触发盲点。

## 为什么有些广告跳不掉

无障碍服务只能读控件树里的文字，**拿不到屏幕像素**：

| 广告实现方式 | 能否跳过 |
|---|---|
| 原生文字按钮「跳过」 | 能，秒点 |
| WebView 里的 H5 跳过 | 多数能 |
| 整图 / 视频 + 自绘按钮 | 读不到，只能靠坐标兜底 |
| 控件被标记为无障碍忽略 | 完全读不到 |

百度系产品（尤其百度网盘）会在倒计时期间向无障碍暴露**首页内容**而不是广告界面，「跳过」按钮出现得比画面晚几秒，属于已知的情况。

## 安装

下载 [Releases](https://github.com/Y3ccccccc/Kill-AD/releases) 里的 APK 安装，然后：

1. 打开「杀死广告」，点「打开无障碍设置」
2. 在「已下载的服务」里找到「跳过开屏广告（无障碍服务）」并打开
3. 回到应用确认没有红色提示条

> 覆盖安装后，部分系统会自动关闭无障碍服务，需要重新打开一次。

## 构建

不需要 Gradle，只要 JDK 17 + Android SDK（build-tools 的 `aapt`/`d8`、platform 的 `android.jar`）：

```bash
./build.sh
```

产物在 `build/SplashSkip.apk`。
